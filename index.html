WorkSelected

AI-driven automated testing

Built from scratch

Manual regression testing was slow, and only developers could write automated tests. I built a framework that lets anyone write a test as plain-language steps.

  • AI turns each plan into a Playwright spec, recording real selectors live against the running app.
  • Self-healing runs: when a selector breaks, AI repairs it and re-runs; genuine failures are logged as bugs automatically.
  • Runs locally or on GitHub Actions, publishes Allure reports, and alerts the team in Microsoft Teams.
  • Imports test cases straight from Azure DevOps, so QA, business analysts and developers all contribute.

Outcome Wider test coverage, less manual regression, and testing adopted across departments, not just engineering.
